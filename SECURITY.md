# Security policy

pillbox handles staff schedules. Two kinds of report matter:

- **A vulnerability** in the app, API or solver.
- **Real data in the repository**: a real name, the pharmacy's identity or a real schedule in
  code, history, an issue or a PR (ADR-008).

Please **do not** open a public issue for either. Report privately through GitHub:
**Security → Report a vulnerability** on this repository. You will get an answer within a few
days.
